# SPARK Report filler (Google Apps Script)

เติมตัวเลขรอบล่าสุดลงไฟล์รายงาน Sangthai (สำเนาของเดือนก่อน) จาก JSON ของ tool `get_monthly_report_data`
**Phase 1:** วันที่รอบรายงาน (ปก + Overview) · Overview (งบ Facebook/Google, Search/GDN/GMB/VDO, Page Like) · หัวตัวเลขหน้าสาขา 17 หน้า + Page Like ชัยภูมิ (สี % ตามกติกาทีม)
**Phase 2:** หน้าสาขา — ตาราง **Ads Target** (Result, CPA, Budget, MoM ของแต่ละ ad set จับคู่กับแถวด้วยชื่อ ไม่แตะคอลัมน์ชื่อของทีม) และกล่อง **Ads Creative** อันดับ 1–3 (Message / CTR ของครีเอทีฟที่รวมโฆษณาชื่อเดียวกัน)
**Phase 1b:** ตารางสรุป Google (หน้า 24, 26, 28, 30) และ Facebook (หน้า 35, 37, 39) — จับคู่แถวด้วยชื่อที่ทีมตั้ง (ไม่ต้องตรงทุกตัวอักษร: ตัวพิมพ์เล็กใหญ่, เว้นวรรค/ขีด, คำนำหน้า, ส่วนท้ายหลัง " - ") เติมเงิน/คลิก/Conv./CPC/CPA หรือ Views/CPV และผลต่าง + วันที่ในหัวตาราง (Current/Previous) ของตารางที่เติมแล้ว แถวที่ไม่มีข้อมูลสคริปต์จะแจ้ง
**เพิ่มแล้ว:** LINE Ads (Overview + หน้า Gain Friend / Conversion) และ LINE OA (เพื่อนสะสม + บรรทัด Broadcast)
**ติ๊กเลือกเองในกล่องเติมข้อมูล (แทนรูปเดิมของทีม):** กราฟอายุ×เพศ (Engagement / Page Like / Reach) และรูปครีเอทีฟอันดับ 1–3 ของแคมเปญหลัก 3 สไลด์ — ลิงก์รูปของ Meta หมดอายุเร็ว ให้สร้างรายงานแล้วเติมทันที
**ยังไม่เติม:** TikTok, SEO, Competitor, Key Finding, รูปครีเอทีฟของสไลด์สาขา

## ดึงจากระบบ (pull mode, v4)
เมนู **ดึงข้อมูลล่าสุดจากระบบ…** ดึง JSON ของรายงานที่ข้อมูลครบจาก `https://conversion.sparkth.io/api/report-exports/` ด้วยคีย์ `cfr_` (สร้างที่หน้า รายงานรายเดือน ของแบรนด์) — ตั้งค่าคีย์ที่ **ตั้งค่าคีย์เชื่อมต่อ…** (เก็บใน Script Properties: ผู้แก้ไขสคริปต์อ่านได้) · ต้องมีสิทธิ์ `script.external_request` ใน `appsscript.json` · ครั้งแรกกดอนุญาตใหม่ · มีขั้นตรวจรอบ/เวลา/จำนวนช่องก่อนเติม · ไฟล์ใหม่: `PullDialog.html`, `SettingsDialog.html`

## ติดตั้ง (ครั้งเดียวต่อไฟล์ — ทำบนไฟล์สำเนา TEST ก่อน ห้ามทำบนไฟล์กลางจนกว่าจะทดสอบผ่าน)
1. เปิดไฟล์สำเนาใน Google Slides → **Extensions → Apps Script**
2. สร้างไฟล์ให้ครบ 4 ไฟล์ ก๊อปเนื้อหาจากโฟลเดอร์นี้:
   - `Code.gs` (เปลี่ยนชื่อ Code.gs ที่มีอยู่) · `Core.gs` (Add a file → Script) · `Dialog.html` (Add a file → HTML ชื่อ `Dialog`)
   - `appsscript.json`: Project Settings → ติ๊ก "Show appsscript.json manifest file in editor" แล้วแทนที่เนื้อหา
3. Save → กลับมาที่ไฟล์สไลด์ → รีเฟรชหน้า จะมีเมนู **SPARK Report**
4. ครั้งแรกที่กดเมนู Google จะขออนุญาต (แสดงเฉพาะบัญชีของคนที่กด) → Advanced → Go to … (unsafe) → Allow
   (บัญชีทีมอยู่โดเมนเดียวกัน คำเตือนนี้ควรเกิดครั้งเดียวต่อคน)

## ใช้งาน (ทุกเดือน)
1. ทำสำเนาจากรายงานเดือนก่อน (สคริปต์ติดมากับสำเนา)
2. เรียก tool `get_monthly_report_data` (organization_id แสงไทย, `period_end`, `plan`) ดู `workflows/monthly_report.md`
3. คัดลอก JSON จากหัวข้อ **"7. JSON สำหรับสคริปต์เติมสไลด์"** (เฉพาะข้อความในกล่อง ```json)
4. เมนู **SPARK Report → เติมข้อมูลจาก JSON…** วาง → เติมข้อมูล → อ่านสรุป (เติมแล้ว / ตรงอยู่แล้ว / ข้าม / ไม่พบ)

## กติกาที่สคริปต์ทำ
- เลือกกล่องจากข้อความอ้างอิง (เช่น หน้าที่ชื่อ "Message Campaign" + ชื่อสาขา) ไม่ใช้ตำแหน่ง และ **ข้ามกล่องที่อยู่นอกสไลด์** (กล่องข้อความเก่าที่ทีมพักไว้)
- แทนเฉพาะ "ค่า" หลังเครื่องหมาย `:` ป้ายหัวข้อและช่องว่างเดิมคงอยู่ พยายามคงฟอนต์/ขนาด/ตัวหนา/สีของค่าเดิม
- เติมซ้ำได้: สคริปต์จำค่าที่เติมล่าสุดของแต่ละช่อง ถ้าในสไลด์ไม่ตรงกับที่เติมไว้ = ทีมแก้เอง → **ข้ามและแจ้ง** (ติ๊ก "ทับ" ถ้าต้องการทับจริง)
- ช่องแผนงบ: ถ้าไม่ส่ง `plan` ให้ tool สคริปต์จะเปลี่ยนเฉพาะตัวเลขใช้จริง และคงข้อความ "(แผนที่ตั้งไว้: …)" ของทีม
- สถานะหน้า "Engagement …(…)" ใน Overview: เติมเฉพาะงบ ผลลัพธ์ทีมกรอกเอง

## เช็กลิสต์ทดสอบบนไฟล์สำเนา (ทำตามลำดับ)
1. **ฟอนต์/สไตล์**: เติมแล้วดูหน้า 4 และหน้าสาขา 1 หน้า — ฟอนต์ ขนาด ตัวหนา สีของตัวเลขต้องเหมือนเดิม สระไทยไม่ลอย
2. **เติมซ้ำ 2 รอบ**: รัน JSON เดิมอีกครั้ง → ต้องขึ้น "ตรงอยู่แล้ว" ทั้งหมด ไม่มีหน้าเบิ้ล
3. **ทีมแก้เอง**: พิมพ์ทับตัวเลขบางช่อง แล้วรัน JSON ใหม่ → ช่องนั้นต้องถูก "ข้าม" และแจ้งชื่อช่อง
4. **ตัวเลขถูกต้อง**: เทียบกับตัวเลขในสรุปของ tool (เช่น บางเลน ฿3,416.29 · 213 ครั้ง)
5. **เวลา**: ดูว่ารันเสร็จกี่วินาที (ลิมิต 6 นาที)
