# Knowledge 02: Creative Framework — HOOK–STORY–OFFER + Creative Metrics
### ConversionFactor MCP · AI Reference File

> "Creative is the New Targeting" — ในปี 2025–2026 อัลกอริทึม Meta ให้ความสำคัญกับ Creative มากกว่า Manual Targeting
> ชิ้นงานที่ดีจะ **บอก Algorithm เองว่าควรยิงไปให้ใคร**

---

## 1. ทำไม Creative ถึงสำคัญกว่า Targeting

เมื่อ Meta เปิดตัว Advantage+ Audience และ Broad Targeting อย่างเต็มรูปแบบ:
- Manual interest targeting มีผลน้อยลง
- Algorithm จะดูว่า "ใครตอบสนองต่อ Creative นี้" แล้วหาคนแบบนั้นมาให้เอง
- Creative กลายเป็น Filter ที่คัดกรองคน: ถ้าภาพ/วิดีโอไม่ตรง Audience จะ scroll ผ่าน → Algorithm เรียนรู้ว่าชิ้นนี้ไม่ดี

**กฎ:** ถ้า CTR ต่ำ อย่าไปแก้ Targeting ก่อน — ตรวจ Creative ก่อน

---

## 2. Framework หลัก: HOOK–STORY–OFFER

### H — Hook (0–3 วินาทีแรก)
จุดที่ตัดสิน 80% ว่าคนจะหยุดดูหรือ scroll ผ่าน

**สิ่งที่ Hook ที่ดีต้องมี:**
- Visual ดึงดูดสายตาภายใน 1 frame แรก: movement, bold color, face, text overlay
- Statement ที่ทำให้คนสงสัยหรือรู้สึกเชื่อมโยง
- Format: Mobile-first, 9:16 vertical หรือ 1:1 square
- ห้าม logo ใหญ่ขึ้นมาก่อน — คนยังไม่สนใจแบรนด์คุณใน 0–3 วิ

**ประเภท Hook ที่ได้ผล (เลือกตาม Audience Stage):**
| ประเภท | ตัวอย่าง | ใช้เมื่อ |
|--------|---------|---------|
| Problem Hook | "ทำไมโฆษณาคุณ CTR ดีแต่ไม่มียอดขาย?" | Cold Audience ที่มีปัญหา |
| Curiosity Hook | "เคล็ดลับที่แบรนด์ใหญ่ไม่อยากให้รู้" | Cold + Warm |
| Social Proof Hook | "10,000 คนใช้แล้ว ได้ผลแบบนี้" | Warm Audience |
| Urgency Hook | "เหลืออีก 48 ชั่วโมง" | Hot Audience / Retargeting |
| Before/After | เห็นผลลัพธ์ทันที | ทุก Stage |

### S — Story (3–15 วินาที / วินาทีที่ 3–ย่อหน้าที่ 2 ในบทความ)
เนื้อหาที่ต้องสร้าง Trust และ Desire

**สิ่งที่ Story ที่ดีต้องมี:**
- พูดถึง Pain Point ด้วยภาษาที่ Audience ใช้เอง (ไม่ใช่ภาษาแบรนด์)
- Social Proof: รีวิว, จำนวนคนใช้, Before/After, ผู้เชี่ยวชาญพูด
- ข้ามจุด: Feature → Benefit → Emotion (คนซื้อ emotion ไม่ใช่ feature)
- อย่าบอกทุกอย่าง: ให้ความสงสัยพอที่จะคลิกต่อ

### O — Offer + CTA (ส่วนท้าย)
ปิดดีลหรือ drive action

**CTA ต้องสอดคล้องกับ Objective:**
| Objective | CTA ที่เหมาะ |
|-----------|------------|
| Awareness | "เรียนรู้เพิ่มเติม" |
| Traffic | "อ่านต่อ / ดูเพิ่มเติม" |
| Lead | "กรอกฟอร์มรับฟรี" |
| Sales | "ซื้อเลย / สั่งซื้อตอนนี้" |
| Messenger | "ทักหาเราได้เลย" |

**กฎ:** CTA บนภาพ/วิดีโอต้องตรงกับ CTA Button ของ Ad เสมอ

## 3. Creative Metrics ที่สำคัญ (ต้องตั้ง Custom Columns)

### Hook Rate (Thumbstop Rate)
วัด: ความสามารถดึงให้คนหยุดดูใน 3 วินาทีแรก

```
Hook Rate = (3-second video plays / Impressions) × 100
```

| Range | ความหมาย | Action |
|-------|---------|--------|
| < 15% | Hook แย่มาก | เปลี่ยน Hook ทันที |
| 15–25% | ต่ำกว่า benchmark | ปรับ Visual/Text แรก |
| 25–35% | มาตรฐาน | ดู Hold Rate ต่อ |
| 35–50% | ดีมาก | Scale ได้ |
| > 50% | Gold Standard | เก็บ DNA ไว้ทำ Variation |

### Hold Rate
วัด: คนที่หยุดดูแล้ว ยังดูต่อจนถึง 15 วินาทีไหม

```
Hold Rate = (ThruPlays / 3-second video plays) × 100
```

| Range | ความหมาย |
|-------|---------|
| < 30% | Story ไม่ engag — คนรู้สึกถูกหลอกจาก Hook |
| 30–50% | ปกติ |
| > 50% | Content ดึงดูดมาก |

### Outbound CTR (oCTR)
วัด: คนที่คลิกออกไปยังเว็บไซต์จริงๆ (ไม่ใช่แค่คลิก Like/Comment)

```
oCTR = (Outbound Clicks / Impressions) × 100
```

- มาตรฐาน: > 1–1.5%
- ถ้า oCTR ต่ำแต่ Hook Rate สูง → Offer/CTA มีปัญหา ไม่ใช่ Hook

### Frequency
วัด: คนคนเดียวเห็นโฆษณาเดิมกี่ครั้งเฉลี่ย

```
Frequency = Total Impressions / Total Unique Reach
```

| Range | ความหมาย | Action |
|-------|---------|--------|
| 1.0–2.5 | ปกติ (Cold Audience) | ไม่ต้องทำอะไร |
| 2.5–3.5 | เริ่มน่ากังวล | เตรียม Creative ใหม่ |
| > 3.5 | Ad Fatigue — อันตราย | เพิ่ม Creative ทันที หรือ Pause |

## 4. Creative Mix ที่แนะนำ (4 Buckets)

| Bucket | % Budget | เป้าหมาย | ตัวอย่าง Creative |
|--------|---------|---------|-----------------|
| **Trigger** (Problem/Solution) | 15–20% | คนที่มีปัญหาชัดเจน | "ปัญหาคือ... วิธีแก้คือ..." |
| **Exploration** (Education/Story) | 25% | สร้าง Awareness | How-to, Behind the scenes |
| **Evaluation** (Trust/Proof) | 25% | Build Trust | รีวิว, Case study, Comparison |
| **Offer** (Conversion) | 30–40% | ปิดการขาย | ส่วนลด, Limited time, Social proof + CTA |

## 5. การ Test Creative แบบมีระบบ

**กฎสำคัญ: 1 Variable ต่อ 1 Test เท่านั้น**

ถ้าเปลี่ยนหลายอย่างพร้อมกัน จะไม่รู้ว่าอะไรทำให้ผลดีขึ้นหรือแย่ลง

**โครงสร้างที่แนะนำ:**
```
3 Concept × 3 Variation = 9 Ads ต่อรอบ Test

Concept 1 (Problem Hook):
  - Variation A: Video 15 วิ
  - Variation B: Static Image
  - Variation C: Carousel

Concept 2 (Social Proof Hook):
  - 3 variations...

Concept 3 (Curiosity Hook):
  - 3 variations...
```

**เมื่อไหรสรุปผล:** รอ 3–7 วัน หรือเมื่อมี Impressions > 2,000 ต่อ Ad

## 6. Creative กับ Audience Stage: ต้องสอดคล้องกัน

| Audience Stage | ประเภท Creative | สิ่งที่ต้องสื่อ |
|----------------|----------------|---------------|
| **Cold** (ไม่รู้จักแบรนด์) | Educational, Problem-Awareness | "นี่คือปัญหาของคุณ และเรามีคำตอบ" |
| **Warm** (เคยเห็นแล้ว) | Product Demo, Comparison, Social Proof | "ทำไมต้องเลือกเรา" |
| **Hot** (เคย Visit/ATC) | Retargeting Offer, Urgency, DPA | "ยังไม่ตัดสินใจ? นี่คือเหตุผล" |

## 7. Diagnostic: ปัญหา Creative อยู่ที่ไหน?

| อาการ | ปัญหาที่แท้จริง |
|-------|---------------|
| Hook Rate < 25% | Visual/Text แรกไม่ดึงดูด → เปลี่ยน Hook |
| Hook ดี แต่ Hold Rate < 30% | Story ไม่สอดคล้องกับ Hook หรือ Boring |
| Hold Rate ดี แต่ oCTR < 1% | Offer/CTA ไม่น่าสนใจ หรือ Audience ไม่ใช่ |
| oCTR ดี แต่ CVR ต่ำ | Landing Page มีปัญหา — ไม่ใช่ Creative |
| Frequency > 3.5 + CTR ลด | Ad Fatigue — ต้องเปลี่ยน Creative |
| CPM สูงผิดปกติ | Audience แคบเกิน หรือ Relevance Score ต่ำ |

## 8. AI Prompts สำหรับสร้าง Creative

### วิเคราะห์คู่แข่ง (ใส่ลิงก์ Ad Library)
```
"วิเคราะห์โฆษณานี้จาก Meta Ad Library:
1. Hook ที่ใช้คืออะไร? (Problem/Curiosity/Social Proof?)
2. สูตร Copywriting คืออะไร? (PAS/AIDA/Storytelling?)
3. Pain Point ที่กระตุ้นคืออะไร?
4. ข้อเสนอ (Offer) คืออะไร?
5. กลยุทธ์ Counter-positioning ที่เราควรใช้?"
```

### สร้าง Hook 5 แบบ
```
"สร้าง Hook สำหรับโฆษณา [Product] ที่กำหนดเป้าหมาย [Audience]
ให้ 5 Hook ต่างกันโดยใช้:
1. Problem Hook
2. Curiosity/Question Hook
3. Social Proof Hook
4. Contrarian Hook (ขัดแย้งกับความเชื่อทั่วไป)
5. Urgency Hook
แต่ละ Hook ไม่เกิน 2 ประโยค"
```
